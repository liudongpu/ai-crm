# Clio平台功能分析:律所管理系统功能清单
## Executive Summary
Clio并非单一工具，而是一个以 Manage为核心，连接 Grow、 Work、 Draft、 Payments、 Accounting与 for Clients的法律AI平台。其设计逻辑是一条完整链路：从潜在客户首次咨询，到案件承接、法律工作、计费收款、信托与总账会计，再到经营分析与复购口碑。官方将 Manage定位为支持案件、截止日期、文档、客户沟通、时间、计费、支付、会计与报告的日常运营系统。本报告在去重后将功能归为十大领域，并以可直接用于选型对照的清单呈现。

## 1. 平台构成与版本边界
理解功能清单的第一步，是区分产品线与版本边界。同一功能可能在不同版本中可用性不同，选型时不应只看“有没有”，而应确认“在哪个版本、是否需要附加组件”。

| 产品或组件 | 定位 | 关键边界 |
| --- | --- | --- |
| Manage | 律所日常运营核心 | 案件、联系人、日历、任务、文档、时间、计费、支付、会计、报告 |
| Grow | 获客与客户关系管理 | 线索、获客流程、intake表单、预约、电子签名、营销与口碑 |
| Work | 实体法律工作AI | 案件分析、法律检索、策略检验、起草 |
| Draft | 文档自动化 | 模板、法院表格、电子签名 |
| Payments | 在线收款 | 卡、eCheck、支付计划、信托合规收款 |
| Accounting | 法律会计 | 复式总账、银行对账、信托三方对账、财务报表 |
| for Clients | 客户门户与应用 | 安全消息、文档共享、账单查看与支付 |
| for Enterprise / Operate / Vincent | 大型律所与企业法务 | 规模化治理、系统连接、企业级AI |

定价页显示，Starter、Core、Signature、Elite为主要分层；AI自Core起包含在计划中，Grow包含在Elite中，也可作为Core与Signature的附加组件。Elite同时包含Manage与Grow。Signature增加无限制自定义角色、看板式案件阶段、AI报告、多币种与拆分账单等控制能力。

## 2. 获客与客户关系管理: Grow
Grow覆盖“首次咨询到签约客户”阶段。官方称其可响应咨询、按适配性与冲突筛查、预约咨询，并将合格线索转化为客户。

| 功能组 | 功能清单 |
| --- | --- |
| 线索与CRM | 联系人记录、线索来源、获客管道阶段、沟通记录、负责人分配、CRM报告 |
| 获客 intake | 在线 intake表单、自定义 intake问题、按执业领域与地点定制 intake流程、一次性采集并自动填入记录 |
| 资格筛查 | 按律所设定的执业领域、地点与要求筛查、AI线索评分、AI初步 intake对话 |
| 冲突检查 | 在全平台范围内检索潜在利益冲突 |
| 预约与跟进 | 在线预约、自动预约合格线索、自动发送 intake表单、未签协议跟进、非工作时间AI接听与响应 |
| 签约转化 | 费用协议发送、电子签名、在线收款、线索转客户后信息同步至案件与客户记录 |
| 营销 | 电子邮件营销、生日问候与活动邀请、律所动态邮件、快速搭建律所网站、渠道来源与广告效果报告 |
| 口碑与复购 | 结案后自动请求评价、过往客户自动回访、转介与广告支出追踪 |

Grow的CRM能力包括联系人记录、线索来源、管道阶段、沟通、分配与报告，并与 intake表单、排期、电子签名、支付、口碑管理与电子邮件营销相连。

## 3. 案件与事项管理: Manage核心
案件管理是 Manage的中心枢纽。官方描述为：查看完整案件、分配下一步、自动化重复工作、跟踪进展直至完成。

| 功能组 | 功能清单 |
| --- | --- |
| 案件档案 | 案件状态、客户信息、关联联系人、沟通、备注、时间、费用、近期活动集中视图 |
| 自定义数据 | 自定义字段、自定义案件阶段、看板式案件阶段视图 |
| 任务与流程 | 任务分配、任务模板与任务组、截止日期、进度与工作量跟踪、跨案件自动化工作流 |
| 案件流程模板 | 一次设定步骤、负责人、交接与审批，再对同类案件重复应用 |
| 冲突与检索 | 利益冲突检查、全文检索 |
| 活动时间线 | 案件活动、firm动态、编辑记录与审计痕迹 |
| 移动与访问 | iOS与Android移动应用、浏览器端访问、无限文档存储 |

定价对比表确认，案件与联系人管理、任务管理、文档存储、移动应用与律所仪表盘属于各主要计划的共同基础。

## 4. 日历、任务与截止日期管理
的日历以案件为组织方式，听证、提交截止、时效日期与客户会议均可归属案件。

| 功能组 | 功能清单 |
| --- | --- |
| 日历管理 | 按案件归档事件、多日历创建、团队与律所共享日历、事件可见性设置、查看者与编辑者权限 |
| 截止日期计算 | 法院规则截止日期链、从触发日期生成相关截止日期、触发日期变更后重新计算、周末与法院假期调整 |
| 时效管理 | 时效日期专用视图、时效日期集中查看 |
| AI日历辅助 | 从法院排期令或通知中提取日期、生成待确认草稿事件、每个日期可追溯来源、已上传含截止日期文档的提醒 |
| 同步与提醒 | 与日历和365双向同步、邮件邀请、短信邀请与提醒、事件创建与变更提醒 |
| 日历与计费联动 | 从日历事件直接添加时间记录、显示尚未记录时间的事件 |

法院规则功能在部分计划中提供，用户可选择司法管辖区与触发日期，由系统添加相关截止日期。

## 5. 文档管理与文档自动化: Draft
文档能力分为两层：Manage中的案件文档管理，以及 Draft的模板与法院表格自动化。

| 功能组 | 功能清单 |
| --- | --- |
| 文档存储与管理 | 无限文档存储、按案件组织文档、文档上传、编辑、共享、版本跟踪 |
| 模板自动化 | 将律所模板转化为可重复使用的自动化草稿、利用案件已有信息填充文档 |
| 法院表格 | 自动化可填写法院表格、按法院要求格式收集电子签名 |
| 电子签名 | 内置电子签名、签名栏直接加入文档、客户与相关方可通过移动端或网页签署、无需创建账户 |
| 协作与版本 | 文档共享、版本历史、文档与案件关联 |
| Word集成 | Work支持在 Word中继续起草与编辑 |

Manage官方页面也明确包括文档的存储、组织、编辑、共享与签名，以及版本跟踪。

## 6. 客户沟通与客户门户: for Clients
Manage将邮件、短信、安全消息与会议记录整合为统一沟通视图。

| 功能组 | 功能清单 |
| --- | --- |
| 统一沟通 | 邮件、短信、安全消息、会议记录集中查看、沟通自动归档至案件 |
| 邮件归档 | 与邮件自动归档、会议录音、转录与摘要 |
| 客户门户 | 客户通过网页或移动端发消息、共享文档、查看预约与账单、在线支付 |
| 自动跟进 | AI起草客户更新供审核、按设定节点自动发送消息与提醒 |
| 电话与会议 | 电话集成生成案件通话记录、视频会议链接加入日历邀请、短信集成保留客户短信记录 |
| 客户自助 | 客户查看账单与支付历史、查看案件进展、提交文档 |

for Clients允许客户发消息、共享文档、查看预约与账单，并从网页或移动端支付。

## 7. 时间、费用与计费
时间与计费是律所现金流的核心。的计费流程包括记录时间与费用、AI起草账单、审批、发送、收款与催收。

| 功能组 | 功能清单 |
| --- | --- |
| 时间记录 | 计时器、手动时间记录、移动端与浏览器端记录、从日历事件生成时间记录、未记录时间提醒 |
| 费用记录 | 费用记录、收据上传、AI预填供应商与日期与明细、费用与案件关联 |
| 费率与计费模式 | 按小时、固定费用、风险代理并行、自定义费率、案件费率与客户条款可见 |
| 账单生成 | AI根据已记录时间与费用起草账单、账单草稿自动路由审批、账单审批前不可发送与入账 |
| 发票与发送 | 品牌发票、发票通过邮件、客户门户或LEDES文件发送、批量开票 |
| 电子账单 | UTBMS任务代码、LEDES导出、复杂账单要求、多方拆分账单、多币种计费 |
| 应收与催收 | 应收账龄报告、逾期分组、自动催款提醒、支付计划、未付余额跟踪 |
| 计费审批 | 账单负责人与审批人分离、账单编辑与审核历史、费率变更与减免的审批路径 |

官方计费页面指出，账单草稿在批准前不能发送、下载为最终发票或计入应收账款；权限可将起草、审批与发送分离。同一页面确认UTBMS任务代码与LEDES导出包含在内。

## 8. 支付、信托与法律会计
这是区别于通用管理软件的关键部分：信托资金必须与运营资金分离，并支持三方对账。

| 功能组 | 功能清单 |
| --- | --- |
| 在线支付 | 信用卡、借记卡、eCheck、Pay、Pay、客户门户支付、发票链接支付 |
| 支付计划 | 分期支付、自动扣款、常青信托retainer、信托定金支付计划 |
| 信托会计 | 信托与运营账户分离、IOLTA账户设置、信托交易按客户与案件记录、信托退款支持 |
| 对账 | 信托三方对账、运营账户双向对账、银行对账单匹配、历史对账报告保留 |
| 总账会计 | 复式总账、银行与信用卡交易通过近实时同步、银行交易建议匹配、自定义匹配规则 |
| 财务报表 | 资产负债表、利润表、现金流量表、按案件盈利报告、律所财务报表 |
| 应付与支出 | 供应商账单跟踪、支票打印、收据费用采集、费用分类 |
| 会计协作 | 外部会计师与记账员受限访问、会计师免费许可 |

会计页面确认，银行与信用卡交易通过近实时到达，并提供建议匹配；信托对账比较银行记录、客户信托台账与信托负债。同一页面确认会计包含在每一项计划中。支付页面确认，按信托会计与IOLTA规则处理信托交易，已赚与未赚资金分开，信托账户不受第三方扣款影响。

## 9. 实体法律工作AI: Work
Work面向实质法律工作：分析案件、研究法律、检验策略、起草文档。

| 功能组 | 功能清单 |
| --- | --- |
| 案件分析 | 跨案件文档、沟通与截止日期分析、时间线生成、关键事实与索赔、义务、风险与缺口识别 |
| 法律检索 | 超10亿份全球法律文档检索、按案件事实与管辖区匹配案例与法规、引证核查、每条引用可链接至原文 |
| 策略检验 | 反方论点与证据缺口识别、不同路径比较、策略压力测试 |
| 起草 | 摘要、时间线与论点起草、按案件背景与法律依据起草、模板文档自动化、法院表格填充、定制复杂文档起草 |
| 文档审阅 | 合同分析、修订审阅、风险识别、尽职调查、笔录与录音分析 |
| 引用与验证 | 引用可追溯、引证有效性检查、输出供人工审核 |
| 权限继承 | 继承 Manage权限，仅可见授权案件 |

Work称其答案来自10亿多份全球法律文档，每条引用均链接至来源。其内置引证工具在引用前确认法律依据仍然有效。
