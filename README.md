# LexDesk · 律所管理平台

面向律师事务所的核心运营管理系统，参考 Clio 的 Manage / Grow 理念，覆盖从咨询线索、利益冲突检查、案件承办，到日历截止日期、文档、时间费用、账单收款、信托与经营分析的完整链路。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 后端 | NestJS 12 + TypeORM 0.3 + SQLite（better-sqlite3） |
| 前端 | React 19 + TypeScript + Vite 8 + Material UI 7 + Emotion |
| 图表 | Recharts |
| 拖拽 | dnd-kit |
| 数据请求 | TanStack Query |

## 目录结构

```
apps/
├── api/    # NestJS API，默认 http://localhost:3000/api
└── web/    # React 前端，开发模式默认 http://localhost:5173
data/       # SQLite 数据库文件（首次启动自动创建并写入演示数据）
doc/
├── prod.md # Clio 律所平台功能分析参考
└── todo.md # 任务与完成记录
```

## 本地运行

```bash
npm install
npm run dev
```

- 前端：http://localhost:5173
- 接口：http://localhost:3000/api

也可以分别启动：

```bash
npm run dev:api
npm run dev:web
```

## 生产模式

生产模式会自动构建前后端，并由 API 同源提供前端页面：

```bash
npm run start
```

然后访问 http://localhost:3000 。也可以先执行 `npm run build`，再运行：

```bash
npm run start:prod -w @ai-crm/api
```

## 功能模块

- **工作台**：核心经营指标、案件阶段分布、待办任务、近期案件、营收趋势
- **案件管理**：案件档案、案号、执业领域、负责人、阶段看板（拖拽改阶段）、详情关联视图
- **客户与联系人**：客户档案、联系人、主从关系、状态与行业、详情与关联案件
- **咨询线索与 Intake**：线索管道、来源、评级、负责人、利益冲突检查、一键转化为客户/联系人/案件
- **日程与任务**：任务、截止日期、庭审/法院事件、优先级、完成状态、按到期分组
- **文档管理**：案件文档、分类、版本、电子签署标记、模板与关联
- **时间与费用**：计时/手动时间记录、费用记录、可计费标记、未开票统计
- **账单与收款**：账单草稿、审批、发送、作废、支付记录、应收余额
- **支付与信托**：信托存取、retainer、已赚费用、对账标记、收款流水
- **沟通记录**：邮件、短信、电话、会议、客户消息，关联案件与客户
- **报表**：营收趋势、执业领域分布、人员工时与产出、Top 客户、线索来源、任务分布
- **全局搜索**：跨客户、联系人、案件、线索、文档的即时搜索
- **设置与权限**：用户/角色、案件阶段配置

首次启动时，后端会自动创建 `data/crm.sqlite` 并填充律师、客户、联系人、案件阶段、案件、线索、任务、文档、时间费用、账单、支付、信托交易、沟通与备注等演示数据。删除该文件后重启即可重置。
