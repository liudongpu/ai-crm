# LexDesk · 律所管理平台

面向律师事务所的核心运营管理系统，参考 Clio 的 Manage / Grow 理念，覆盖从咨询线索、利益冲突检查、案件承办，到日历截止日期、文档、时间费用、账单收款、信托与经营分析的完整链路。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 后端 | NestJS 12 + TypeORM 0.3 + SQLite（better-sqlite3） |
| 前端 | React 19 + TypeScript + Vite 8 + Material UI 7 + Emotion |
| 图表 | Recharts |
| 拖拽 | dnd-kit |
| 数据请求 | TanStack Query |

## 目录结构

```
apps/
├── api/    # NestJS API，默认 http://localhost:3000/api
└── web/    # React 前端，开发模式默认 http://localhost:5173
data/       # SQLite 数据库文件（首次启动自动创建并写入演示数据）
doc/
├── prod.md # Clio 律所平台功能分析参考
└── todo.md # 任务与完成记录
```

## 本地运行

```bash
npm install
npm run dev
```

- 前端：http://localhost:5173
- 接口：http://localhost:3000/api

也可以分别启动：

```bash
npm run dev:api
npm run dev:web
```

## 生产模式

生产模式会自动构建前后端，并由 API 同源提供前端页面：

```bash
npm run start
```

然后访问 http://localhost:3000 。也可以先执行 `npm run build`，再运行：

```bash
npm run start:prod -w @ai-crm/api
```

82 个二级功能全部为真实可用页面，**不再保留通用“功能记录”占位页**：

- **18 个核心业务功能**由成熟业务页面承载：客户、联系人、线索、案件、任务、日程管理 6 项、文档、沟通、时间/费用记录、账单、信托会计、报表等。
- **64 个二级功能**已真实化。后端新增统一的「可扩展工作台」领域（`/api/workspace`），每个功能由后端驱动一份专属 schema（专属字段类型与选项、状态机、统计口径、本地配置开关），前端渲染为独立工作台页面（路由 `/workspace/<功能编码>`），具备真实的筛选、分页、新建、编辑、删除、详情、状态流转、统计卡片与本地配置持久化。业务型功能有专属字段与业务记录，配置型功能以“本地配置台”提供可持久化的开关/文本/数值/下拉配置，分析型功能提供基于演示数据的统计与记录跟踪。

82 个二级功能各自对应唯一路由，顶部一级菜单与侧边栏二级菜单的激活状态按“精确路径优先、查询参数次之、最长路径兜底”解析。案件管理的「任务与流程」使用独立的 `/tasks` 任务管理页，日程管理的「日历管理」使用 `/calendar`，两者不再冲突；计费模块的「账单生成」与「发票与发送」通过 `?new=1` 区分，信托会计模块的「在线支付」使用 `/workspace/payment_online` 工作台页面。

其中 **日程管理** 的 6 个二级功能均为真实可用页面，不依赖通用记录或演示数据：

- **日历管理**：月/周/列表视图、多日历与案件筛选、事件可见性、提醒提前量，支持新建、编辑、完成与删除。
- **截止日期计算**：配置法院规则与节假日，从触发日期生成期限链，触发日期变更后重新计算，周末与节假日自动顺延，可一键生成日程。
- **时效管理**：诉讼时效台账，按起算日与期间自动计算到期日，提供临近到期与逾期预警、状态流转。
- **AI日历辅助**：从法院通知或文档文本中按本地规则识别日期并提取上下文，生成待确认日程草稿，确认后写入真实日历，保留来源可追溯；不调用外部 AI 服务。
- **同步与提醒**：标准 ICS 文件导入/导出，以及事项提醒规则与待发送队列；不连接第三方云服务。
- **日历与计费联动**：列出尚未记录工时的日程，一键生成工时记录并统计已关联工时与金额。

> 集成生态、法律智能、安全合规、`payment_online` 等功能以本地配置与演示数据承载，开关与参数可真实修改并持久化到当前演示库，但不会发起对第三方系统的调用、法律 AI 推理或认证审计。

首次启动时，后端会自动创建 `data/crm.sqlite` 并填充律师、客户、联系人、案件阶段、案件、线索、任务、文档、时间费用、账单、支付、信托交易、沟通、备注，以及 12 个功能目录、82 个二级功能；日程管理的 6 个功能使用真实业务数据，64 个工作台功能按各自专属 schema 生成真实演示记录与本地配置。删除该文件后重启即可重置。
